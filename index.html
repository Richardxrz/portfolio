工程笔记

决策记录（ADR）与踩过的坑 —— 代码之外，真正可复用的部分。

ADR-001 · 舵机总线

拆成两条 3+3 总线

问题
单总线挂 6 轴，轮询读角只有 27 Hz，控制环跟不上
选项
提高波特率 / 拆总线 / 只读必要字段
选择
拆两条总线，各挂 3 轴
代价
多一路 UART，代码要支持双实例与独立调度
结果
每轴约 56 Hz，角度指令与反馈链路稳定
ADR-002 · CAN 架构

对象池 + 发布订阅

问题
多电机共享一条 CAN，回调散落，加一个轴就要改多处
选项
全局回调表 / 每个电机独立线程 / 对象池 + 订阅
选择
对象池管理电机实例，收发按 ID 分发到订阅者
代价
多一层间接，调试时要看路由表
结果
新增关节只注册不改核心，40 条主机侧用例全绿
ADR-003 · 本站 3D

模型内嵌而不是 XHR 加载

问题
双击打开页面时浏览器禁止本地 XHR，OBJ 永远加载不到
选项
要求起本地服务器 / 改用 data 内嵌 / 只放静态图
选择
把 OBJ + MTL 转成 JS 字符串，用 parse() 直接解析
代价
首屏多 3.7 MB，且改动模型要重新生成
结果
双击即可旋转查看，材质 128 组 / 19 色正常

踩过的坑

  • DMA + IDLE 变长帧：max_len = 0 会把整帧毁掉 —— 参数必须校验，主机侧测试台先跑。
  • 重复 open 静默失效：句柄已占用时不报错，只返回旧状态 —— 加状态检查与显式错误码。
  • CSS 覆盖 [hidden]：灯箱写 display:flex 会让遮罩常驻，必须补 [hidden]{display:none}。
  • file:// 下 fetch / XHR 必失败：媒体探测改用 <img>/<video> 的 onload / onerror。
  • 立创EDA 只导 OBJ：没有 MTL 时颜色全丢，必须把同名 .mtl 一起带上。
  • 1080p 素材直接上网页：单条 30–380 MB —— 统一转 720p / CRF 27，7 条视频压到 17 MB。
