# PCB 3D 导出与网页展示

## 一、立创EDA专业版导出 3D

| 步骤 | 操作 |
|---|---|
| 1 | 打开 PCB 文件（`.eprj2` 里的 PCB 页） |
| 2 | 顶部菜单 **视图 → 3D 预览**（或左侧工具栏的 3D 图标） |
| 3 | 3D 窗口中找 **导出** 按钮（部分版本在右键菜单 / 顶部工具栏） |
| 4 | 格式选 **OBJ**（网页直接用）；需要结构装配再另存 **STEP** |

> 标准版只能导 OBJ；专业版支持 OBJ + STEP。

## 二、网页怎么用

1. 把 OBJ 改名 `pcb-51.obj`，放进 `assets/models/`；
2. 有 `.mtl` 就一起放，改名 `pcb-51.mtl`；
3. 刷新页面 → 首页「PCB 3D 模型」区块自动变成**可拖动旋转**（滚轮缩放、双击复位）。

没有模型时该区块显示 `pcb-51-3d.jpg` 静态图 + 提示，不会报错。

## 三、STEP 转网页格式（如只有 STEP）

| 工具 | 做法 |
|---|---|
| **FreeCAD**（免费） | 导入 STEP → 选中对象 → 文件 → 导出 → OBJ / glTF |
| **Blender** | 装 STEP 插件 → 导入 → 导出 glTF（.glb） |
| 在线转换 | 可用但不建议：板上文件含设计信息 |

## 四、注意事项

- 立创EDA 的 OBJ 可能内嵌材质、没有独立 MTL → 网页用默认蓝灰材质渲染；想保色就先用 Blender 转标准 OBJ+MTL；
- 模型面数过大（>50 万面）会卡：导出前可简化，或只导关键器件；
- 网页只加载 **OBJ**，不解析 STEP。
